🚀 CryptoSlices – Cryptocurrency Market Insights Dashboard

CryptoSlices is a real-time cryptocurrency analytics platform that provides market insights for major cryptocurrencies such as Bitcoin, Ethereum, Solana, Cardano, and more.
The application fetches live data from the CoinGecko API and visualizes market trends through interactive charts and dashboards.

🌐 Live Demo: https://cryptoslices.netlify.app
💻 GitHub Repository: https://github.com/mithun0773/crypto-place

📊 Features

🔄 Real-Time Cryptocurrency Data

Fetches live data using the CoinGecko API

📈 Market Analytics Dashboard

Displays price trends, market capitalization, and 24-hour price changes

📉 Interactive Data Visualization

Charts built using Recharts for better trend analysis

🪙 Multiple Cryptocurrency Support

Bitcoin

Ethereum

Solana

Cardano

Dogecoin and more

⚡ Fast and Responsive UI

Built with React.js

🔗 API Used

This project uses the CoinGecko API to retrieve cryptocurrency market data.

Example endpoint used:

https://api.coingecko.com/api/v3/coins/markets

Parameters used:

vs_currency=usd

order=market_cap_desc

per_page=20

page=1

sparkline=false

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/mithun0773/crypto-place

Navigate into the project directory:

cd crypto-place

Install dependencies:

npm install

Run the development server:

npm run dev

The application will run at:

http://localhost:5173
